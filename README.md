# 로컬 체스 코치

## 설치와 사용

1. `start-coach.cmd`를 실행하고 창을 열어 둡니다.
2. Tampermonkey에서 **새 스크립트 만들기**를 누르고 기본 내용을 전부 지웁니다.
3. 같은 폴더의 `chess-local-coach.user.js` 내용을 전부 붙여 넣고 Ctrl+S로 저장합니다. `userscript.template.js`는 설치용이 아닙니다.
4. Chess.com을 새로고침합니다. Tampermonkey에서 로컬 주소 `127.0.0.1` 연결 허용을 요청하면 허용합니다.
5. 개별 대국 결과 페이지에서 **우클릭 → 이 대국 로컬 분석·코치 리뷰**를 누릅니다.

예: https://www.chess.com/game/live/185631914754?username=curlymeister

페이지의 대국 ID를 공개 완료 기록과 대조한 후 분석합니다. URL에 `username`이 없으면 패널에 자신의 Chess.com 아이디를 입력합니다. 최근 두 개의 기록 월에서 최대 100국을 표시하며, 과거 게임은 월을 지정해 조회하세요. 기록 반영이 지연되거나 한 달에 100국 이상 두었다면 해당 대국의 PGN 파일을 내려받아 **완료 대국 PGN 열기**를 사용할 수 있습니다. 표준 체스의 완료된 단일 대국 PGN만 지원합니다.

페이지 내부 우클릭 메뉴입니다. 브라우저의 기본 우클릭 메뉴는 Shift+우클릭으로 열 수 있습니다. Tampermonkey 확장 메뉴와 우측 하단 **로컬 코치** 버튼에서도 접근 가능합니다.

## 분석과 통계

### 등급 배지와 평가 표시

- 기보의 분류 열, 코치 카드, 마지막 기물 도착 칸에 로컬 등급 배지를 표시합니다. 배지에 마우스를 올리면 근거를 볼 수 있습니다.
- `★ 최선`은 저장된 엔진 첫 후보와 일치할 때 표시합니다. 나머지는 손실 0.20폰 이하 `+ 훌륭`, 0.50폰 미만 `✓ 좋음`, 0.50폰 이상 `?! 부정확`, 1폰 이상 `? 실수`, 2폰 이상 `?? 큰 실수`로 구분합니다. 메이트 장면은 별도 처리합니다.
- `!! 탁월 후보`는 첫 후보와 일치하며, 손실 0.20폰 이하이고, 이미 3폰 이상 유리하지 않았으며, 이후 평가가 -0.30폰 이상인 수에서 확인합니다. 저장된 상대 첫 대응이 폰 이외 기물을 잡고 다음 응수까지 기물 점수가 출발 때보다 최소 2점 줄어드는 경우를 희생 후보로 표시합니다. 유일한 합법 수는 제외합니다. 짧은 엔진 수순으로 추정하므로 희생의 충분한 보상·난도·공식 탁월수 판정을 보증하지 않습니다.
- Chess.com은 별도의 기대 점수 모델과 희생 기준을 사용합니다. 이 앱의 배지는 공식 Chess.com/Lichess 판정과 동일하지 않습니다. [공식 분류 설명](https://support.chess.com/en/articles/8572705-how-are-moves-classified-what-is-a-blunder-or-brilliant-etc)
- 그래프에는 현재 수의 세로선·점·번호·평가가 나타납니다. 원하는 위치를 클릭하거나 그래프에 초점을 두고 방향키·Home/End를 누르면 해당 기보로 이동합니다. 가상 수순 중에는 원래 대국의 **분기 출발점**을 표시합니다.
- 보드 왼쪽의 흑백 막대와 점수는 현재 위치의 **백 기준 평가**입니다. `+`는 백 우세, `−`는 흑 우세입니다. 보드를 뒤집으면 막대의 흑백 방향도 바뀝니다. 막대 비율은 평가를 시각화한 값이며 승률이 아닙니다.
- 저장된 평가가 없는 학습·가상 위치에는 `평가` 버튼을 표시합니다. 클릭하면 그 위치를 엔진으로 계산하며 보고 있던 수순은 그대로 유지됩니다. 숫자를 클릭해 재계산할 수도 있습니다.

### 수순을 따라 배우기

- 저장된 분석과 새 분석 모두 첫 수를 두기 전 시작 포지션에서 열립니다.
- **추천 수 따라보기**: 현재 선택한 수를 두기 전 위치에서 엔진 수순을 고정합니다. `다음 한 수` / `이전 한 수` 또는 수순 버튼으로 이동합니다. 이동할 때마다 엔진을 다시 계산하지 않습니다.
- **내 수와 비교**: 동일한 출발 위치에서 실제로 둔 첫 수와 엔진이 예상한 이후 대응을 봅니다. 실제 대국의 나머지 수순과 다를 수 있습니다.
- **스스로 찾아보기**: 첫 후보를 숨기고 보드에서 직접 찾습니다. 다른 후보를 선택하면 정답/오답을 단정하지 않고 엔진 비교로 연결합니다. `정답 공개`와 `다음 수 화살표`도 사용할 수 있습니다.
- **여기서 직접 두기**: 지금 보고 있는 단계의 정확한 포지션에서 자유 분석을 계속합니다. **추천 수 보기 종료** 또는 오른쪽 **추천 수 보기 끄기**는 학습을 시작하기 전 기보/가상 수순으로 돌아갑니다.
- 각 단계는 기물 이동, 잡기, 체크, 캐슬링, 승격 등을 실제 합법 수순으로 확인하여 설명합니다. 기물 점수 변화와 저장된 엔진 평가는 별도로 표시합니다. 모든 전략적 이유를 설명하는 대화형 AI는 아닙니다.
- 엔진 수순은 최대 16반수의 예시이며 상대에게 강제된 유일한 수순이라는 뜻이 아닙니다. 단계별로 표시된 수순 평가를 재계산하지 않습니다.
- 후보 3수 계산 후에도 **수순 따라보기**와 **이 수 두고 재분석**을 구분해 사용할 수 있습니다.

### 레이아웃과 단축키

**최대화**하면 왼쪽에 보드, 오른쪽에 코치·평가 그래프·기보를 배치합니다. 창 크기를 복원할 수 있으며 좁은 화면에서는 세로로 배치됩니다. 분석을 열면 대국 조회 설정은 접혀 보드 공간을 확보합니다.

패널이나 보드를 클릭하여 초점을 준 뒤 사용하세요. 아이디·검색 입력 중에는 적용되지 않습니다.

| 키 | 기능 |
| --- | --- |
| ← / → | 기보 또는 학습 수순에서 한 수 이동 |
| Home / End | 현재 기보·수순의 시작 / 끝 |
| F | 최대화 / 복원 |
| B | 보드 뒤집기 |
| R | 추천 수 따라보기 |
| H | 학습 중 다음 수 화살표 켜기 / 끄기 |
| Esc | 수순 학습 중이면 학습만 종료하고 원래 복기 위치로 복귀. 일반 복기에서는 패널 닫기 |

참고한 기능: [Chess.com Game Review](https://support.chess.com/en/articles/10328363-how-do-i-use-game-review-on-the-app)의 수순 보기·재시도, [Chess.com 분석 보드](https://support.chess.com/en/articles/8583825-how-do-i-use-the-analysis-board)의 후보와 화살표, [Lichess 실수 복습](https://lichess.org/@/lichess/blog/learn-from-your-mistakes/WFvLpiQA), [DecodeChess](https://decodechess.com/chess-threat-analysis/)의 보드와 설명 연결. 로컬 기능을 독립적으로 구현했으며 이 서비스들의 비공개 설명 엔진이나 평가 체계를 복제한 것은 아닙니다.

- Stockfish 19로 모든 수 전후 포지션을 평가합니다. 빠른 분석은 최대 깊이 14·포지션당 180ms, 깊은 분석은 최대 깊이 20·900ms입니다. 시간 한도로 실제 깊이는 낮을 수 있습니다.
- 기보 행을 클릭하면 독립적인 복기 보드, 백 기준 평가, 추천 변화, 한국어 설명을 확인합니다.
- 보드에서 기물과 도착 칸을 차례로 클릭하거나 드래그하면 가상 수순을 분석합니다. 둘 수 있는 칸은 점으로 표시합니다. 현재 기보의 수를 바꾸려면 **현재 수 대신 두기**를 먼저 누르세요.
- 가상 수마다 최대 1.5초·깊이 20으로 최대 3개 후보와 후속 수순을 계산합니다. 각 후보의 실제 탐색 깊이도 표시합니다.
- **가상 수 무르기**, **원래 기보로**, 승격 기물 선택을 지원합니다. 가상 수순은 저장된 대국과 누적 통계를 바꾸지 않습니다. 마지막 이동의 출발 칸은 노란색, 도착 칸은 초록색입니다.
- 한국어 코치는 엔진 결과를 설명하는 규칙 기반 기능입니다. 외부 AI API나 Chess.com의 유료 코치를 사용하지 않습니다. 전술의 원인을 자연어로 완전히 해설하는 AI 모델은 아닙니다.
- **최근 5국 분석·통계**, **최근 20국 분석·통계**는 현재 조회한 목록에서 최신순으로 각각 5국·20국을 순서대로 분석한 뒤 누적 통계와 강점·약점 요약을 표시합니다. 조회 결과가 더 적으면 있는 대국만 분석합니다. 월을 지정했다면 그 월의 목록을 기준으로 합니다.
- 일괄 분석 중에는 `진행 대국/전체 대국`과 수별 진행 상황을 표시하고 취소할 수 있습니다. 각 대국이 끝날 때 화면을 전환하지 않으며, 통계에는 이번 묶음뿐 아니라 기존에 저장된 분석도 포함됩니다.
- **내 누적 통계**는 입력한 아이디가 백/흑으로 참여한 저장 대국을 합산합니다. 초반·중반·종반, 색상, 오프닝 ECO, 최근 5국과 직전 5국을 비교합니다.
- 단계 기준: 양쪽의 나이트·비숍·룩·퀸 합산 기물 가치가 20 이하이면 종반, 나머지에서 첫 20반수는 초반, 이후는 중반입니다. 포지션 특성을 완전히 구분하는 기준은 아닙니다.
- 평가 손실은 수 전후 독립 탐색의 차이입니다. 엔진 첫 후보를 둔 경우는 손실 0으로 처리합니다. 메이트 장면은 평균 손실·실수율에서 제외합니다. 폰 0.5/1/2 이상의 손실을 각각 아쉬운 수/실수/큰 실수로 분류합니다.
- 강점·약점은 구간마다 최소 3국·30수 이상일 때 비교합니다. 10국 미만의 결론은 잠정적입니다. 상대 강도, 시간제한, 포지션 난도는 보정하지 않습니다.
- 공식 Chess.com 정확도·브릴리언트 분류·추정 레이팅과 동일하지 않습니다. 수순 반복은 포지션 단독 평가에 반영되지 않을 수 있습니다.
- `data` 폴더에 분석을 저장합니다. 동일 PGN을 다시 분석하면 결과를 덮어씁니다. 통계는 저장된 분석만 사용하므로 전체 Chess.com 계정 통계와 다릅니다.

## 문제 해결

- 버튼이 안 보임: Tampermonkey에서 스크립트를 활성화하고 Chess.com을 새로고침하세요. 브라우저가 요구하면 확장 설정에서 사용자 스크립트 실행을 허용하세요.
- 연결 실패: `start-coach.cmd`가 실행 중인지, Tampermonkey의 로컬 주소 연결 권한이 허용되어 있는지 확인하세요.
- 포트 사용 중: 이미 실행한 서버 창을 사용하세요. 동시에 두 서버를 실행하지 마세요.
- 인증 실패: 서버와 같은 폴더의 생성된 `.user.js`를 다시 붙여 넣으세요.
- 중단: 패널의 분석 취소를 누르거나 서버 창을 닫으세요.

서버는 `127.0.0.1:8765`에만 연결되며 무작위 인증 키를 요구합니다. 비밀번호·쿠키는 읽지 않습니다. 외부 통신은 Chess.com의 공개 완료 기보 조회에 사용됩니다. 설치용 스크립트와 `config.json`에는 개인 로컬 인증 키가 들어 있으므로 그대로 공유하지 마세요. 배포 시에는 템플릿을 공유하면 됩니다.
