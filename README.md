# Local Chess Coach v1.0 설치 안내

Windows PC의 Stockfish 엔진으로 **완료된 Chess.com 대국**을 분석하고 Chrome 안에서 복기하는 도구입니다. Chess.com·Lichess의 공식 제품이 아닙니다. 별도의 유료 API 키는 필요하지 않습니다.

## 1. 준비물

- Windows 10/11 **64비트 Intel/AMD PC**. ARM Windows, macOS, Linux, 모바일은 이 배포판에서 지원하지 않습니다.
- Google Chrome.
- [Node.js 공식 다운로드](https://nodejs.org/en/download)의 **24 이상 LTS 버전**, Windows x64 설치 프로그램.
- [Tampermonkey 공식 홈페이지](https://www.tampermonkey.net/)에서 Chrome용 확장 프로그램.
- 설치 시 인터넷 연결. Stockfish 다운로드는 약 80MB이며 압축을 풀 공간도 필요합니다.

Node.js 설치 시 기본 옵션을 사용하세요. 설치가 끝나면 이미 열려 있는 명령 프롬프트 창은 닫으세요. npm 명령을 따로 실행할 필요는 없습니다.

## 2. 배포 ZIP 압축 풀기

1. 배포자가 제공한 `local-chess-coach-v1.0.zip`을 받습니다.
2. 파일 탐색기에서 ZIP을 우클릭하고 **모두 압축 풀기**를 선택합니다.
3. 예를 들어 `C:\Tools\LocalChessCoach`처럼 쓰기 가능한 개인 폴더에 풉니다. ZIP 내부에서 바로 실행하지 마세요.
4. `install.cmd`, `start-coach.cmd`, `coach` 폴더가 있는 위치를 엽니다.

관리자 권한이나 `Program Files` 설치는 필요하지 않습니다.

## 3. 엔진 설치 및 개인 스크립트 생성

1. `install.cmd`를 더블클릭합니다.
2. 설치 창이 Stockfish 19를 공식 GitHub에서 다운로드하고 SHA-256을 확인합니다.
3. `Installation ready.`가 나오면 설치가 완료된 것입니다. 아무 키나 눌러 창을 닫습니다.

설치 과정에서 다음 파일이 생성됩니다.

```text
coach/config.json                 내 PC의 로컬 연결 인증 키
coach/chess-local-coach.user.js    내 PC용 Tampermonkey 스크립트
engines/stockfish/                Stockfish 엔진 및 원본 안내 파일
```

`install.cmd`는 해당 설치 프로세스에만 PowerShell 실행 정책을 지정합니다. 시스템 전체 실행 정책을 변경하지 않습니다. 회사·학교 PC 정책으로 실행이 막히면 조직 정책을 따르세요.

## 4. 로컬 서버 실행

1. `start-coach.cmd`를 더블클릭합니다.
2. `Local Chess Coach: http://127.0.0.1:8765`라는 문구가 나타나는지 확인합니다.
3. **분석하는 동안 이 창을 열어 두세요.** 서버를 종료하려면 창을 닫습니다.

컴퓨터를 다시 켰을 때도 분석 전에 이 파일을 실행하면 됩니다. 자동 시작이나 외부 서버는 설정하지 않습니다.

## 5. Chrome에 스크립트 등록

1. Chrome의 확장 프로그램 메뉴에서 **Tampermonkey → 대시보드 → 새 스크립트 만들기(+)**를 엽니다.
2. 편집기에 들어 있는 기본 코드를 전부 지웁니다.
3. 파일 탐색기에서 `coach/chess-local-coach.user.js`를 **메모장으로 열기** 합니다. 더블클릭으로 JavaScript를 실행하지 마세요.
4. 전체 내용을 `Ctrl+A`, `Ctrl+C`로 복사하고 Tampermonkey 편집기에 붙여 넣습니다.
5. `Ctrl+S`를 눌러 저장합니다. 스크립트가 켜져 있는지 확인합니다.

`userscript.template.js`는 설치용이 아닙니다. 반드시 설치 프로그램이 생성한 **`chess-local-coach.user.js`**를 사용하세요.

## 6. Chrome 권한 확인

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. Tampermonkey의 **세부정보**를 엽니다.
3. **사용자 스크립트 허용(Allow User Scripts)** 항목이 있으면 켭니다. Chrome 버전에 따라 개발자 모드가 필요할 수 있습니다. [Tampermonkey 공식 안내](https://www.tampermonkey.net/faq.php#Q209)
4. Tampermonkey가 Chess.com에서 실행되도록 사이트 액세스 권한을 확인합니다.
5. `127.0.0.1` 연결 허용을 묻는 Tampermonkey 창이 나오면 이 스크립트의 연결을 허용합니다. `@connect` 대상은 로컬 PC입니다.
6. 브라우저가 별도로 이 확장의 로컬 네트워크 접근 허용을 요구하면 로컬 서버 연결에 필요한 권한을 허용합니다.

방화벽의 외부 포트를 열거나 공유기 포트 포워딩을 설정할 필요는 없습니다.

## 7. 첫 분석

1. Chess.com의 **끝난 대국 결과 페이지**를 열고 새로고침합니다.
2. 페이지를 우클릭하고 **이 대국 로컬 분석·코치 리뷰**를 선택합니다. 우측 아래 **로컬 코치** 버튼도 사용할 수 있습니다.
3. 아이디가 자동 입력되지 않으면 자신의 Chess.com 아이디를 입력합니다.
4. 분석이 끝나면 시작 포지션부터 기보를 볼 수 있습니다.

개별 대국 주소는 보통 `https://www.chess.com/game/live/대국번호` 형태입니다. 사이트 공개 기록 반영이 늦으면 해당 대국의 PGN을 내려받아 **완료 대국 PGN 열기**로 불러오세요. 표준 체스의 완료된 단일 대국만 지원합니다.

## 8. 주요 기능

- 기물 클릭 후 도착 칸 클릭 또는 드래그로 가상 수순 분석.
- 추천 수순을 고정해서 한 수씩 보기, 실제 수와 비교, 답을 가리고 찾아보기.
- **추천 수 보기 종료**, 오른쪽 **추천 수 보기 끄기**, 또는 `Esc`로 학습 전 복기 위치에 복귀.
- 최대화하면 왼쪽 보드, 오른쪽 코치와 기보.
- 보드 왼쪽 평가 막대·점수. `+`는 백 우세, `−`는 흑 우세이며 막대 비율은 승률이 아닙니다.
- 그래프 현재 위치 표시 및 그래프 클릭으로 해당 수 이동.
- 수 등급 배지. `!! 탁월 후보`는 자체 희생 탐지 결과로 공식 Chess.com 판정과 다릅니다.
- **대국 가져오기 → 최근 20국 분석·통계**로 조회한 목록에서 최신 20국 분석. 20국 미만이면 있는 대국만 분석합니다.
- 분석 결과는 `coach/data`에 저장되며, 누적 통계에는 기존 저장 분석도 포함됩니다.

패널 안을 클릭한 후 단축키를 사용하세요.

| 단축키 | 기능 |
| --- | --- |
| ← / → | 이전 / 다음 수 |
| Home / End | 시작 / 끝 |
| F | 최대화 / 복원 |
| B | 보드 뒤집기 |
| R | 추천 수순 보기 |
| H | 학습 중 다음 수 화살표 |
| Esc | 학습 중에는 추천 수 보기 종료, 일반 복기에서는 패널 닫기 |

더 자세한 판정 기준과 제한은 `coach/README.md`를 참고하세요. 전체 분석 코치는 규칙·엔진 수순 기반이며 사람 코치나 대화형 AI와 같은 설명 능력을 제공하지는 않습니다.

## 9. 자주 생기는 문제

| 현상 | 해결 |
| --- | --- |
| Node.js가 없다는 안내 | 공식 LTS를 설치한 뒤 설치 창을 다시 엽니다. |
| 엔진 다운로드 실패 | 인터넷과 GitHub 접근 상태를 확인하고 `install.cmd`를 다시 실행합니다. |
| 체크섬 불일치 | 다운로드가 손상되었거나 파일이 바뀐 것입니다. 실행을 중단하고 배포자에게 확인하세요. |
| Chrome에서 버튼이 안 보임 | Tampermonkey·스크립트 활성화, 사용자 스크립트 허용, 사이트 권한을 확인한 뒤 새로고침합니다. |
| 로컬 서버 연결 실패 | `start-coach.cmd` 창이 실행 중인지와 로컬 연결 허용 여부를 확인합니다. |
| 포트 8765 사용 중 | 같은 프로그램의 서버 창이 이미 열려 있는지 확인합니다. 중복 실행하지 마세요. |
| 인증 키 불일치 | 현재 설치 폴더의 `coach/chess-local-coach.user.js`를 다시 복사해 저장합니다. |
| 대국이 조회되지 않음 | 아이디와 조회 월을 확인합니다. 공개 기록 반영 전이면 완료 대국 PGN을 사용합니다. |
| 분석 중 취소하고 싶음 | 분석 설정을 펼쳐 **분석 취소**를 누릅니다. 완료된 대국은 저장되어 있습니다. |

## 10. 업데이트·백업·삭제

업데이트 전에 서버 창을 닫습니다. 새 배포판을 **별도 폴더**에 풀고, 기존 `coach/config.json`과 `coach/data`를 새 폴더의 같은 위치로 복사하면 키와 분석 기록을 유지할 수 있습니다. `install.cmd`를 실행한 뒤 새로 생성된 스크립트를 Tampermonkey에 다시 붙여 넣으세요. 기존 스크립트 항목을 수정하고, 중복 스크립트를 켜 두지 마세요.

기존 개발판 v1.3.x를 사용하던 사람도 배포판 v1.0으로 옮길 때는 위와 같이 수동으로 코드를 교체합니다. 개발판과 첫 공개 배포판의 버전 번호는 서로 다른 기준입니다.

삭제할 때는 서버를 종료하고 Tampermonkey에서 스크립트를 삭제한 뒤 설치 폴더를 지우면 됩니다. 필요하면 `coach/data`를 먼저 백업하세요.

## 개인정보와 연결 범위

서버는 이 PC의 `127.0.0.1:8765`에만 연결됩니다. Chess.com 비밀번호나 로그인 쿠키를 요청하지 않습니다. 엔진 설치 시 GitHub, 기보 조회 시 Chess.com 공개 API와 통신합니다.

`coach/config.json`, 생성된 `coach/chess-local-coach.user.js`, `coach/data`는 개인 파일입니다. 다른 사람에게 공유하지 마세요. 설치 후 사용한 폴더 전체를 재압축해서 배포하지 말고, 배포자가 제공한 깨끗한 ZIP을 공유하세요.
